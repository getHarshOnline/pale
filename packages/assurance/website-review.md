# Assess one proposed website data operation

Identify the site or publication, affected people, exact data flow, purpose, recipient, retention and time horizon. Trace generated and derived data, cross-site and onward use, remaining copies, and the system responsible for each action. Establish roles and applicability from the supplied authority and evidence.

## Trace the trigger and the receiving boundary

For each route, distinguish a rendered link, automatic browser request, user-initiated navigation, data submission and subsequent processing by the recipient. Inspect the configured destination, rendered output and browser behaviour separately. Include embedded assets, redirects, background requests and optional integrations where they affect the operation. State which user action or permission state triggers each flow. A shared page or service name does not make the site, operator, off-site recipient and later handler one owner.

For browser checks, fix the candidate, route, browser, state and observation window. Test initial load, denied or absent choice, the permitted action and relevant withdrawal or revisit. Use a harmless stand-in for a live recipient or consequential action unless the owner authorises that exact test. If the claim concerns receipt or persistence, compare browser requests with the actual state at the recipient or store. A link's presence does not establish browser traffic. An absent request establishes absence only within that observation. A request trace cannot establish the provider's retention, erasure, authority or adequacy of notice.

Return a supportable, conditional, unsupported or unresolved assessment, with the evidence still needed from each owner. If the act depends on consent or separately governed publication permission, request consent review for that exact scope and keep that requirement open in the initial assessment. A generic privacy statement, product label or collection permission does not settle a new purpose, recipient or delivery route.

## Before handing off

- [ ] Trace the actual data from collection to its destinations.
- [ ] Check purpose, terms and settings for the intended flow.
- [ ] Name unverified processing and the decision still required.
