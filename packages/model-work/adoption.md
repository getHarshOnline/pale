# Assess a proposed use of machine learning

Specify the decision, inputs available at prediction time, error costs and accountable owner. Compare the proposed model with a deterministic, manual or simpler current method on a defined population and outcome. Identify the smallest part of the system where learning could help and the working fallback if it fails. Return a scoped recommendation and the smallest comparison that could disprove it. Use the owning systems and permissions for any data access, training or rollout.

## Before handing off

- [ ] Is the outcome the model could improve clear?
- [ ] Was it compared with the current method under actual costs and failures?
- [ ] Is it clear what observation would justify wider use?
