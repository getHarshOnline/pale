# Review how a reader can discover a publication

Identify the publication, canonical route, rendered artifact, audience question and evidence sought. Read the actual output before interpreting diagnostics. Distinguish crawl and routing checks, index eligibility, observed index state and traffic. A valid link or sitemap establishes its corresponding output behaviour. In the review, identify the missing route, observation or owner decision. Index submission and deployment are separate actions.

## Before handing off

- [ ] Was the intended route opened and its discovery configuration checked?
- [ ] Is it clear what current output and observations establish?
- [ ] Are untested discovery and indexing questions left open?
