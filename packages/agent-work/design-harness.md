# Design an agent's working environment

Start with the outcome, permitted actions, governing sources and a way to check completion. In the design, trace each decision and action through its adapter, permission, result record and stopping path. Describe fallbacks and unavailable routes separately. Identify the engine or service responsible for scheduling, accepting work, execution, continuity and recovery. Return a reviewable plan with the controls and checks it needs.

## Before handing off

- [ ] Are the work, tool effects and necessary human decisions clear?
- [ ] Can the available tools enforce the intended limits?
- [ ] Has a failure and the route back to useful state been exercised?
