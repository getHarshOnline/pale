# Preserve meaning across presentations

Use this when the same subject appears in an index, article, figure, search result, alternate mode or another medium. Decide which facts and relationships carry across and which presentation choices can change. Follow each source to the person or system that owns it.

| If you are doing this | Read this |
| --- | --- |
| Find which model supplies each part of a view | [Resolve each input from the source that owns it](presentation/resolve-the-inputs.md) |
| Compose the same object in an index, reading view or figure | [Keep facts and relationships through a change of form](presentation/preserve-the-payload.md) |
| Handle withheld, missing or unsupported content | [Keep the task available when information is missing](presentation/show-an-honest-gap.md) |
| Compare emitted payloads or a fallback | [Check what the reader receives in each form](presentation/compare-forms.md) |
| Decide the page’s main task and which tools to show | [Choose the presentation from the reader’s task](presentation/choose-a-reading-mode.md) |

## Before handing off

- [ ] Do the facts, qualifications and relationships survive each affected version?
- [ ] Does each version suit the task its presentation serves?
- [ ] Are gaps clear while useful content remains available?
