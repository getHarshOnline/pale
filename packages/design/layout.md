# Compose meaning in space

Use this when an opening, group, figure or page needs a clearer composition. Decide what the reader should recognize first, what they need to compare or act on, and how those relationships fit the available space. Use the project’s direction and real content.

| If you are doing this | Read this |
| --- | --- |
| Order different kinds of content | [Set visual weight from meaning](layout/weight.md) |
| Compose an opening or let a figure cross the grid | [Use a grid and decide where to depart from it](layout/grid.md) |
| Clarify grouping, spacing or useful empty space | [Tune density and the space between things](layout/density.md) |
| Find the reason for a crowded or misleading composition | [Check a layout on the rendered page](layout/check.md) |

## Before handing off

- [ ] Does the layout make the intended recognition, comparison or action clear?
- [ ] Are related elements grouped intelligibly against unrelated content?
- [ ] Do the opening, reading order and type work at the relevant widths?
- [ ] Does a recurring defect have a correction in the shared layout or spacing rule?
