# Check design source and capture rendered pages

Run these commands from the Pale checkout or call them by path.

- `python3 static_audit.py PATH …` scans HTML, CSS, Sass and script sources. Add `--token-roles`, `--template-emoji` or `--fixed-width-limit CSS_PX` for the project’s actual rules. An `--authored-source FILE` exclusion applies to token rules for that scene-only file. `--json` prints the check result.
- `python3 check_sources.py --root ROOT FILE …` checks links within the supplied root. Use `--machine-paths` or `--private-terms FILE` when required by the publishing owner. Use `--online` only for source URLs the project can contact. Unchecked links and unresolved responses are reported as skipped.
- `node capture.mjs --profile PROFILE --out DIR URL …` uses Playwright and an installed Chromium. Use a workspace with Playwright or set `PLAYWRIGHT_MODULE` to the installed module. The [fixture profile](fixtures/capture-profile.json) shows the fields. Provide viewport widths and target sizes in CSS pixels. Add the optional `preferences` mapping only for a project that exposes those storage keys and attributes. `--routes system,explicit` exercises both routes when the mapping exists.
- `node capture.mjs --verify-captures DIR/cells.json` verifies the recorded images. `capture.mjs --json` reports the manifest, cells and problems. The cells describe the browser run. Traversal records text actually encountered in the viewport; a text node that remains fully transparent throughout its visits fails as `unrevealed-text`. Each visit allows up to one second for native arrivals without stopping animation. Inert regions, `aria-hidden` content, closed panels, screen-reader-only labels and text covered by another element do not count as missing arrivals. Hit testing separates exposed text from a covered card or clipped local scroller; vertical traversal does not exercise those components’ selection or horizontal scrolling. Gradient-filled and shadow-painted text remain valid. This check establishes arrival, not legibility or contrast. Inspect the captures and exercise keyboard, focus, motion and recovery as appropriate to the actual task.

Use `--viewport` for an explicitly limited first-viewport image after traversal. Each cell records `captureScope` as `viewport` or `full-page`; measurements still describe the traversed document. Chromium’s full-page capture can reset touch emulation on a tall page and paint mouse-conditioned styles. This was reproduced through both Playwright and direct `Page.captureScreenshot`; such cells fail the pointer check. A viewport capture preserves touch in the checked fixture, but does not establish full-page touch appearance. Do not reset emulation after taking an invalid image and call it a touch capture.

The commands exit 0 for a passing run, 1 for a failure, and 2 when a requested check was skipped. A local link scan reports external URLs as skipped unless you pass `--online`. The browser checks are `node --test test_capture.mjs test_text_visibility.mjs`. The source checks are `python3 -m unittest discover -s . -p 'test_*.py'` in this folder.

From the Pale root, run `python3 tools/package_navigation.py` to check the family indexes. Closing questions are checked on generated instructions by the application’s `package_pages` compile tests, including both host layouts; source leaves do not need repeated checklists. The [Package maintainer checks](../../docs/package-authoring.md) also exercise links in the rendered Codex and Claude guidance. Run token, template and world checks in the repository that owns those inputs.
