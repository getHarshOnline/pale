# Choose a visual direction from the actual brief

Use this when the work needs a visual and interaction direction or when a repair must recover the qualities of an accepted reference. Decide what the reader should recognize and do, which qualities come from each source, and how the design will express them.

| If you are doing this | Read this |
| --- | --- |
| Decide what the audience needs and what the work should express | [Frame the design problem before choosing a form](art-direction/frame-the-brief.md) |
| Study an inspiration, reconstruction or approved source | [Read the reference for the qualities it supplies](art-direction/read-the-reference.md) |
| Choose material, typography, hierarchy and expressive range | [Turn direction into visible decisions](art-direction/turn-direction-into-design.md) |
| Check a rendered direction against the source | [Judge the whole treatment at delivery scale](art-direction/inspect-direction.md) |
| Diagnose familiar defaults, missing presence or distracting expression | [Recognize unconsidered design choices](art-direction/recognize-defaults.md) |
| Explore several credible directions | [Use a reference board to develop an open direction](art-direction/develop-an-open-direction.md) |
| Compare identities that share an interface system | [Compare identities across the same design system](art-direction/compare-identities.md) |
| Decide what stays quiet and where expression should rise | [Set the expressive range and pace of a page](art-direction/expressive-scale.md) |
| Gather, compare or hand on reference boards | [Build a board that leads to decisions](art-direction/build-a-board.md) |
| Derive an identity from its subject and references | [Give an identity a subject and a working form](art-direction/derive-an-identity.md) |

## Before handing off

- [ ] Do the selected references and their roles explain the visual and interaction choices?
- [ ] Are those choices visible in real content, using the existing system where it serves the work?
- [ ] Does the result hold in the form the reader receives?
