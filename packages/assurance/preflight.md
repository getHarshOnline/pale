# Check a calculation request before execution

Use the calculation preflight to identify one request, the accepted Pack of rules, private snapshot reference, selected implementation, numerical conventions, validation and limits on permitted actions. Keep these details with the review result, including the relevant owner and any unmet requirement. Private inputs stay with the system that owns them.

If the evidence supports handoff, return the preflight finding, responsible owner and exact scope. Missing, conflicting or stale inputs require a stop and the name of whoever can resolve them. This operation neither calculates nor invokes the engine. A passed preflight is separate from a receipt showing execution.

## Before handing off

- [ ] Check the intended evaluation, inputs and permitted scope.
- [ ] Verify the actual route and required dependencies.
- [ ] Stop at the approval or information still needed.
