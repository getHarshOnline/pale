# Review the evidence for a model or dataset

Identify the requested claim and use the smallest permitted way to inspect it. Apply the artifact guide and any provider guidance the project has chosen. Return the revision and file evidence, access and rights observations, and gaps concerning compatibility or use. Provider installation, permission and invocation are separate actions.

## Before handing off

- [ ] Are the model or dataset and source version identified?
- [ ] Have the relevant files, terms and recorded results been checked?
- [ ] Are metadata claims distinguished from observed behaviour?
