# Choose the treatment before making a set

## Settle the image before multiplying it

Separate the qualities shared by the set from what each shot may vary. An approved subject can keep its proportions and materials while the camera, gesture or framing changes. Write down a distinction only when it will guide production or resolve a real ambiguity; an existing brief or annotated board may already do that. A new production sheet is not required for every asset.

If direction is unresolved, compare meaningfully different treatments of the same relevant subject. Judge the principles, rather than merely changing a color or adding finish. Test the chosen treatment on a sufficiently different subject before producing a large set. If direction is already accepted, use it instead of reopening discovery. A provider's style code is a derivative of that direction: retain the references and reasons outside the provider.

Translate references into actionable qualities. Distinguish soft reflected light from a glow effect, a rough surface from added image noise, spatial depth from a blurred background, and a particular contour from generic detail. Inspect the reference itself; an automatic description supplies vocabulary, not an authoritative account of what makes it work.

## Worked example

Make one still with the intended subject, shot size, light and ground. Use it to agree on what stays constant. A companion view can rotate the camera while keeping the subject’s proportion and surface. Compare the two on their intended page. A variant that loses the accepted silhouette needs correction even if it is more polished.
