# Research a finance or compliance question

Identify the exact decision, proposed act, affected roles, period and jurisdiction supplied by the responsible owner. For each condition that determines applicability, record its source, observed version and unresolved facts in the research result. Use only approved references to private evidence. A current lookup or retained source may support a dated candidate proposal; say which was used and keep retrieval separate from acceptance for use.

Return the applicability findings, contradictions, missing evidence and owner responsible for each unresolved condition. Verify a proposal only when a candidate supported by sources exists. Check a calculation request only when an exact accepted basis and a request to the owning calculation engine are available.

## Before handing off

- [ ] Identify the activity, location and relevant period.
- [ ] Read the current primary sources for applicability.
- [ ] Leave unresolved interpretations with the responsible reviewer.
