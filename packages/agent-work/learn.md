# Propose a lesson from completed work

Choose a completed case with identifiable evidence and use the reusable-learning guide. Review the proposal for omissions, then return it with the situations it supports, proposed home, source or originality questions and required owner review. Hold the proposal if outcome evidence or a transferable trigger is missing. Memory updates, Package edits, installation and adoption remain separate actions; the proposal alone does not show that a running system learned.

## Before handing off

- [ ] Does a completed case support the proposed transferable rule?
- [ ] Are the method, local facts and observed outcomes distinct?
- [ ] Is the proposal where its owner can review it?
