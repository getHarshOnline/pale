# Decide whether a temporary workflow helps

Compare doing the work directly with the proposed repeatable workflow, using the same outcome, safeguards and evidence. Before proposing it, define when it stops, expires and is removed. Return a reversible proposal and the recurrence or cost evidence that could justify wider reuse.

## Before handing off

- [ ] Is the recurring task and where it gets stuck clear?
- [ ] Does the workflow resolve a real problem?
- [ ] Is it clear what can be removed once the normal path works?
