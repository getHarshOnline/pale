# Review a media placement

Identify the approved source and publication candidate. Apply the placement guide and independent Design review to compare the actual rendition and surrounding presentation with the brief. Use authorised tools for build and destination observations. In the review, report findings by condition and identify missing observations.

## Before handing off

- [ ] Does the placed media match the approved asset and rendition?
- [ ] Was the actual player or reader view checked, including required fallback?
- [ ] Are the review result and open placement or approval questions clear?
