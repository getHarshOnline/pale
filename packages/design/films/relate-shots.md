# Cut between shots for a reason

Choose what the incoming shot says about the outgoing one. A direct cut, intentional hold or ellipsis can be the strongest answer. The vocabulary below helps test more involved transitions. For reader-driven work, design the reverse from the same pictures.

| Join | What performs it | What it can say | Backward |
| --- | --- | --- | --- |
| Object wipe | Cloth, a door or a passing object crosses the frame | What follows was behind this | The object crosses back and uncovers the first shot |
| Match on shape | An exit shape becomes the entry shape | This becomes that | The shape resolves back |
| Match on action | Movement starts in one shot and completes in the next | The same action continues | The movement runs back across the cut |
| Lens block | A near object fills and clears the frame | A threshold was crossed | The object returns and clears to the first shot |
| Change of medium | The same object stays in place while its material changes | A drawing became an object, or an object became a record | The medium reverts |
| Change of viewpoint | The same subject appears from a new position | A different aspect of the same thing | The viewpoint returns |
| Push through | A detail becomes the next wide shot | The whole is in the part | The view pulls back out |
| Dissolve through ground | The image clears to paper, sky or dark before another forms | Time passed, or a pause | The new shot clears and the earlier one forms |
| Counted step | Each earlier state remains as a numbered panel | The next state in an ordered series | The new panel and number withdraw |
| Laid down in order | Each new frame rests over the earlier ones | This followed that, and the earlier state remains | The top layer lifts away |

At the cut, the eye is usually with the outgoing subject. Put the incoming subject there or use the action to lead the eye. Follow the first landing with the next one. If the viewer must find the subject twice, compare a held match. Let important words appear within the same reading path. Keep ordinary controls and dialogs governed by [Design motion that helps people use the interface](../animate.md) even when the adjacent sequence overlaps shots.

Keep a distinctive cut because its material, light or rhythm serves the project. Palette alone rarely distinguishes the timing of two identities. When separate recordings are joined, a pointer or shape moving into an input can imply an actual transfer. Use that gesture only when the recorded action establishes it.

For an action match, try cutting at the onset of movement and inspect the swap frame by frame, then at normal speed. For a graphic match, overlay the outgoing and incoming frames at half opacity before committing the join. Compare the important shapes’ position, scale and color, then judge the actual cut. Geometric coincidence can support continuity but does not settle whether the edit serves the story.

## Worked example

A product drawing and a close view of the built part have the same curved edge. Register that edge before the cut, then show the physical edge catching light. Keep the caption on the same side. Step backward to see whether the drawing is recognizable again. A travelling pointer would suggest a tool performed the fabrication. The graphic match expresses the relationship without making that claim.
