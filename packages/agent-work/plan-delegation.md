# Plan how the work will be shared

Return a brief for each independently useful part and identify who joins the results. The required delegation method supplies the planning and review steps. The host or accountable owner decides whether and how to start the workers.

## Before handing off

- [ ] Can each recipient act from the request, corrections, sources and approvals in its brief?
- [ ] Does each file have one writer, with dependencies and the integrator clear?
- [ ] Will the returned work answer the task, including disagreements and checks still missing?
