# Read the type on the delivered surface

## Read the actual presentation

Compare the relevant light/dark and reduced-motion states under their selected contracts, and use the accessibility prerequisite for contrast and enlargement. An optical correction should not accidentally change layout or remove meaning. Test spacing overrides and real zoom where applicable. For a live page, readable end states must remain available without expressive movement. For an authored film, inspect kinetic type's legible interval, qualifications and captions in actual playback; the host's motion preference does not rewrite the encoded cut.

Name the changed role or delivery step, the face and features observed, meaningful break and hierarchy findings, and targets still to check. Typeface licences, token values, output settings and approval stay with their owners. No particular font, role count, language, style or typographic taste is prescribed.

| Read in the delivered result | Failure to investigate |
| --- | --- |
| One element from every role, with real script and glyph coverage | A default or synthetic face is mistaken for the intended treatment. |
| Display beside sustained reading and system labels | The voices collapse, or strengthening identity destroys reading stamina. |
| Long title, translated label, numeric pair and copied command | Wrapping changes a relationship, hides a qualification or corrupts literal input. |
| Several full prose lines at wide and narrow widths | Measure expands without a bound, or crowding is answered by shrinking reading text. |
| Same page in light and dark at native scale | Optical weight becomes weak, color and opacity combine below the reading floor, or a correction unexpectedly rebreaks lines. |
| Delayed and blocked fonts on supported platform families | The selected fallback clips text or moves controls; a successful load is assumed from configuration. |
| Reduced-motion page and the actual authored film playback | Page text requires expressive motion to become readable, or the film's complete phrase has no usable reading interval. |

Use the shared [rendered sweep](../inspect/sweep.md) for the surrounding interface checks. A font or hierarchy change can affect navigation, tables, captions and controls beyond the specimen being edited.

## Stress spacing as well as size

For the WCAG text-spacing check, apply line height of at least 1.5 times the font size, paragraph spacing of at least twice the font size, letter spacing of at least 0.12 times the font size, and word spacing of at least 0.16 times the font size together. Check for lost or clipped text and controls at the relevant width. The check asks whether readers can use those settings. It does not prescribe the site's default typography. Apply only spacing properties that the language and script use.

[W3C text spacing criterion](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html).

## Worked example

Read a long label, caption and numeric table on a phone and a desktop. Use the system’s enlargement and a text-spacing override. Check a thin metadata line on each background. For kinetic type, play the film at its intended speed and time how long the full phrase stays readable. A paused frame is a different check from the reading interval in playback.
