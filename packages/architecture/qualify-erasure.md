# Review deletion and invalidation results

Start with the owner's accepted decision and the precise data it covers. Apply the erasure and recovery methods to every copy and dependent view covered by that decision.

In the review reply, list those copies, what each owner observed, stale-read and restore test results, any residual data whose use remains restricted and the actions still needed from copy holders. Distinguish denied access, invalidation and actual deletion. Conclude only what the supplied observations establish.

## Before handing off

- [ ] Identify the copies and consumers the deletion reaches.
- [ ] Check read-back, downstream invalidation and recovery.
- [ ] Name copies or uses that still require a decision.
