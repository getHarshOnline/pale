# Build or repair the requested interface

Read the current request, project constraints, accepted direction and selected references. Identify the user’s task and the surface to change. For a repair, reproduce the symptom and use the system method to find the source that produces it. Preserve the settled composition unless the requested change reaches it. If identity or source intent is unresolved, keep that dependent choice open while continuing the rest.

For a new surface, connect the subject and audience to a concrete treatment: hierarchy, type roles, material and light, emphasis, responsive composition, motion and interaction where applicable. Put those decisions in the existing plan or specification. Read further craft guidance for the decisions the task needs, then build the actual surface.

Use the established components, tokens and implementation route. Keep construction that serves the selected reference, and add shared machinery for a demonstrated recurring need. Fix the owning source once, follow its consumers and remove overrides that the adopted fix replaces. Project values, vocabulary, tool bindings, credentials and approvals remain with the project.

Run the affected source checks and inspect the rendered interface. Reproduce the original failure and exercise the affected states and paths. Compare the result with the brief and references. Use independent review when requested or required, and identify self-review honestly. Correct the source and repeat affected checks until the requested result holds or a specific dependency prevents it; continue work that does not depend on that missing input.

Return the implemented change and, in the existing review or reply, the commands or tools run, observed result, unrun checks and remaining owner decision. The project supplies tool access and release approval. A direct run during setup is useful evidence of that run; credit Pale dispatch only when Pale actually dispatched it.

## Before handing off

- [ ] Does the interface serve the requested task and accepted direction?
- [ ] Does the fix reach the actual consumers of the source that changed?
- [ ] Do the rendered output and affected interactions work, with any untested conditions stated?
