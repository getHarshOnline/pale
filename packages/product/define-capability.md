# Define a product capability

Read the accepted need, the relevant owners' requirements and the product's existing behavior. Describe the ability someone can observe, how to measure success, its constraints, the agreements between parts and what happens on failure. Keep interface, vendor and implementation choices open unless already settled.

Return a capability proposal to the product owner, with its supported scope and the questions that remain.

## Before handing off

- [ ] Does the proposal answer an accepted need?
- [ ] Can the reader identify the outcome, possible failure and supported scope?
- [ ] Can the result be checked in use?
