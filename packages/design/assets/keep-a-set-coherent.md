# Keep an approved treatment coherent across a set

Use this when several assets must belong to one treatment. Start with the chosen direction and the material already approved. A short study can separate real alternatives before expensive generation or rendering. Develop different ways to tell the subject or frame the relationship. Several grades of the same shot answer a different question.

## Set the invariants before producing the set

Turn the direction board into a style board by choosing the few images that best demonstrate the chosen medium, surface, light, optics and human treatment. A quality that appears in only one source can still be central. Identify the source that supplies it. Keep recurring subject references for the geometry, proportions, costume or material a sequence needs to recognize. Declare permitted changes in light, viewpoint, scale or medium and say what anchors continuity through each one.

| Shared across the set | Written for this shot |
| --- | --- |
| Medium and surface, material, palette logic and optics | Claim, state, action and camera or viewpoint |
| Treatment of people and recurring subject references | What enters or leaves the frame and what matches the next shot |
| Lighting logic and limits on change | Intended change in lighting, if the shot calls for one |
| Standing exclusions and any text-placement rules | Needed reading space, labels and shot-specific exclusions |

Where exploration remains open, use a few low-cost territories that differ on named qualities. Reuse an accepted direction within its scope. Once the team agrees on the shared treatment, keep it in one source and point the requests to it. A changed treatment calls for checking the affected assets again. The tool, model and version belong to the run. They are ways to make the treatment, while the treatment names what should survive a tool change.

A production sheet can connect decisions, recurring references, beats, variants, masters, derivatives and checks when a set needs them. Store the assets in their source library and reference them by role and revision. Link the authored film's existing timeline or specification where it already contains the shot and pacing decisions.

## Worked example: keep one material while changing the camera

The approved figure looks like matte ceramic in low side light. Produce the front view before making its companion. Hold the material, silhouette and light direction. Move the camera and change scale only where the new crop needs it. Compare both rendered figures in their actual slots. If one looks metallic, adjust the specular treatment or reference weight and rerun that figure. If both move into an existing film, carry the accepted material directly into the shot plan.
