# Check whether a release is ready to run

Identify the release candidate and its intended operating conditions. Use the research method to check external requirements, then assess readiness for the proposed rollout. Run a project check, scanner or browser inspection only through a tool permitted for that scope.

Return the release assessment with supporting evidence, remaining risks, missing checks and who can decide whether to release it.

## Before handing off

- [ ] Does the assessment name the exact candidate and operating conditions?
- [ ] Does the evidence cover the risks that matter to this launch?
- [ ] Are unresolved checks and the release decision left with named owners?
