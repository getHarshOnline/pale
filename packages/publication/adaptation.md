# Adapt content across media

Adapt accepted content to the requested destinations while preserving its supported claim, evidence and authorial identity. Publication is a separate action.

Read the shared `pale.design/presentation` method exported by `packages/design/package.toml`. It explains what must remain unchanged, owner and reader state, honest gaps and independent output comparison. The Publication declaration includes it once, and the corpus entry helps direct readers find it. Browser review and implementation are separately selected tasks.

## Start from the shared sources

Use the accepted primary artifact, its supported claims and source references, inherited voice, requested destinations and known format requirements. Verify current platform limits through the consuming Pack or actual provider.

For each destination, identify the reader's likely entry context, available attention, media form and parts of the argument that must stay together. Recompose from the common sources. Remove supporting detail only if the claim keeps its qualifications; add orientation without inventing proof.

Preserve directness, uncertainty and rhythm where they carry meaning. Use questions, intimacy, tags or urgency only when the source or brief warrants them. If several entries are needed, each should advance the argument.

Return an identified primary version, requested variants, material adaptation choices, unresolved constraints and any sequencing justified by audience or campaign dependencies. Finish when each variant stands alone, traces to the same evidence and changes where its medium requires it. Describe proposals as proposals until posting, scheduling or platform acceptance is observed.
