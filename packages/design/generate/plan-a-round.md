# Compare a generation hypothesis

## Compare a hypothesis, rather than rerolling a symptom

Choose the next action from the observed defect. If a correct subject sits in the wrong framing, changing style words may destroy accepted treatment without fixing composition. If only one region is defective, a whole-frame reroll reopens every settled choice. If a map holds the wrong structure, correct its type or content before increasing control strength.

For an isolated comparison, hold the relevant input files, model/version, seed and settings stable while changing the suspected cause. Exploration can vary several things. It cannot establish which one produced the difference.

A reroll with the same request samples variation; label it that way. Read the batch as a set of clues before choosing a cause. When every candidate misses in the same way, inspect shared inputs and references. When they miss differently, inspect ambiguity and sampling variation. One close candidate is worth keeping for its selected qualities, but does not prove the request is reliable. A local defect in an otherwise suitable frame usually calls for an edit of that frame.

Image-to-image strength changes how far a pass can depart from its input, and interacts with the pipeline's timestep and scheduler behavior. Do not port a numeric threshold between implementations. Upscaling, tiled detail and refinement can invent content: inspect the complete result and seams, not only the improved patch. More steps, stronger guidance or a different precision are experimental changes, not automatic quality improvements.

## Spend a round on one open production question

| Round | Question it answers | Result that closes it |
| --- | --- | --- |
| Territory | Which direction serves the brief? | The owner selects qualities from comparable studies. There is no approved treatment to enforce yet. |
| Style test | Does the selected treatment hold across different required subjects? | A small set reads as one body; testing only the original subject leaves its wider use unproven. |
| Keyframe | Does this frame carry its beat? | The frame meets the shot and asset checks at the required quality. |
| Edit | Can this region be corrected while preserving the rest? | The correction and the required unchanged regions both pass. |
| Motion | Does the shot move as the beat requires? | The sequence, endpoints and any required reverse playback pass inspection. |
| Variant | Does this required grade, composition or delivery form work? | The variant is checked in its destination; an authored change has its own master, while a delivery conversion remains a derivative. |

Explore territories while the visual direction is open, test identity and material before a whole set, and make the next round a targeted edit when the remaining defect is local. Before judging a batch, read the shared treatment and the current shot. Compare all outputs at the same scale, and separate anatomy, source fidelity, composition and continuity from novelty. Hold the conditions that are irrelevant to the current comparison, then vary one consequential setting. Inspect a changed model or adapter on the same style test before using it on the rest of the set.

For production, inspect honesty, the selected treatment and required continuity first; then the shot and the placement of any words; then craft defects and the frame's expressive quality. Attractive detail does not excuse a failed requirement. For territory studies, judge against the brief and identify promising qualities separately from defects instead of rejecting a study against an unselected treatment.

Before spending a round, check whether the selected tool exposes the needed control. Set its cost and stopping bound from the existing authorization. Stop on the first candidate that answers the production question and meets the applicable checks; this closes the correction, while any required owner acceptance remains separate. Also stop at the agreed budget or when bounded attempts repeat the same defect. A plateau leaves the cause unresolved: inspect the request, references, storyboard, treatment and controls before changing route. Then change the route, strengthen the needed control or choose another form. Use cheap, small candidates while learning and spend full resolution on the candidate that needs it. Keep the request, settings, chosen output and reason in the existing run record, with a short reason for consequential rejections.

Keep a useful discovery without claiming it isolates a cause. Before turning it into a standing instruction, record the tested subjects, tool and model versions, counterexamples and limits. A body-specific pattern belongs with its treatment; a shot-specific pattern belongs with that shot. Recheck a pattern when its dependencies change, and revise the current guidance if it no longer holds while retaining the original run record.

## Worked example

A generated series preserves the shape but loses the soft light from the reference. Make two trials at the same seed, size and settings. Change the reference strength in one and keep the other as a control. Compare light and outline together. If the change fixes the light and breaks the outline, refine the separation of controls instead of keeping the nicest image from a batch that changed several inputs at once.
