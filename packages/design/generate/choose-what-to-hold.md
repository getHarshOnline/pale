# Choose what to hold while generating an edit

## Match the control to what must stay

A request describes the desired picture; repeating its words does not bind the next picture to the previous one. For each detail that must remain, name the mechanism intended to hold it and the comparison that will show whether it worked. If the tool cannot preserve a required detail, use the approved source in an edit or composite, or change the production route.

| Required continuity | Useful control to investigate | Limit to inspect |
| --- | --- | --- |
| Treatment, material or lighting language | Style reference, selected profile or adapter | Can affect subject or composition; does not establish identity |
| A recurring subject | Subject reference or supported multi-image edit | Similar appearance does not guarantee exact geometry or factual identity |
| Position, perspective or pose | Appropriate structural map | Holds encoded structure, not every detail, color or identity |
| A limited correction | Masked edit, supported instruction edit or composite | Unmasked pixels may still change |
| A comparison from similar starting noise | Fixed recorded seed | Neither a style control nor a promise of identical output |
| A prescribed beginning or ending | Explicit supported frame conditioning | An appearance reference alone may constrain neither endpoint |

Select only the controls needed for the invariant. Describe what may vary as well as what must stay. When pixels outside an edit must be exact, verify them or retain them through a deliberate composite. Do not infer preservation from the feature name. Preserve the accepted file as the master instead of assuming its seed and words can recreate it.

Translate the request into the selected version's supported vocabulary and parameters. Negative prompts, weights, reference strengths, editing modes and still/video parameters are not interchangeable across providers or model families. Read the relevant reference before using them. Identify automatic rewriting, selected personalization and account defaults that can change the submitted request. Keep a prepared proposal distinct from what actually ran, including an owner's changes in a manual workflow.

## Verify continuity across the boundary that needs it

A style reference can give a shared surface or palette and still change the subject. A subject reference can hold appearance while moving the camera and light. A structural map holds the structure it encodes. Palette conditioning keeps color choices within a range but does not set the direction of the light. An approved frame can make a stronger starting point than another prompt for the same style.

Put the two frames that need to match next to each other at full size, then at the size the reader will see. A contact sheet can hide a changed face, hem or horizon. Name the invariant and the two files compared; check the silhouette, face, horizon, lighting or pose directly. At a continuous generated join, condition the supported beginning or ending from the known neighboring frame. Check the encoded junction even if both endpoints were supplied, including an unintended jump or duplicate held frame. For an intentional change of composition, inspect whether the cut still carries the needed subject or relationship.

Give each control one stated job in the existing request or graph: the contour it holds, the material it supplies, the region it edits or the endpoint it constrains. Test that job by comparing the result with and without the control. Drop a control that adds no useful preservation or conflicts with a more important one. More conditioning is not automatically more fidelity.

One control asked to do two jobs is a useful first check when continuity fails. A style reference that preserves the lighting may still change the face; add the supported subject control rather than increasing style strength to solve identity. Choose a reference for the quality it should carry: an unrelated polished advertisement may introduce its composition and production style along with the wanted texture. The body's own approved frame often provides a better reference.

Treat a selected taste profile as another input. Record the submitted code or version and strength; a mutable account profile name does not pin its behavior. Disable an unselected profile when it would confound a comparison. A provider's literal mode can reduce embellishment without preserving reference pixels exactly. Check these controls on the selected model, and record necessary changes between shots instead of assuming identical settings establish continuity.

## Worked example

The brief holds the object’s outline and changes its material. Keep a silhouette control or a narrow mask and use the prompt for the material. Compare any result against the original outline and the requested surface. Increase the structure weight only if the object drifts. A stronger map can hold details that should have been allowed to change.
