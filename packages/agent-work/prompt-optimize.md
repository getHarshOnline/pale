# Improve a draft instruction

Identify the task, audience, host, supplied context, constraints and what a good result would show. Keep deliberate ambiguity and voice while repairing omissions that would change the result. Name a tool or component when its current capabilities are known and help the task; otherwise describe what is needed without inventing a component.

Return the revised instruction, a brief explanation of material changes, open assumptions and any component choices checked. Representative prompt checks should show where the instruction leads and whether it causes unwanted work. Improving the instruction is the task here; carrying it out is a separate request.

## Before handing off

- [ ] Does the draft keep the original task and constraints?
- [ ] Do representative checks cover how the instruction is found and unwanted work it might trigger?
- [ ] Does the reply give the draft and what the comparison established?
