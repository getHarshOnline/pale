Use this for cutting, synchronizing, captioning, mixing or adapting supplied media. Read the requested edit and the real sources. Decide what to keep, how its time maps to the cut, and what the destination can show.

## Before handing off

- [ ] Are input order, media clocks and necessary source details preserved?
- [ ] Do speech, text and visible action agree after editing?
- [ ] Does the decoded mix work with the picture?
- [ ] Do the exported file and intended player each behave as required?
