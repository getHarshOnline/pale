# Review a site's search visibility

Review an identified page or site for a defined search objective. Check current search-engine behaviour, index state, traffic, queries, competitors and site configuration from evidence. These observations cannot promise a ranking.

Trace the path to visibility: the URL must be discoverable, fetchable, renderable, eligible for indexing, understandable and useful for the query. Inspect relevant canonical and redirect relationships, robots and sitemap signals, status codes, internal links, rendered content, page purpose, duplication, structured data, language and locale relationships, performance and accessibility. Distinguish technical obstacles from content, authority, demand and measurement problems.

For each finding, identify the URL or template, observation, affected stage, consequence, confidence and smallest correction. Check source and rendered behaviour. A scanner warning points to something to inspect; an indexing request cannot establish inclusion. Prioritise by reach, business relevance, severity and recoverability.

Return inspected scope, evidence, prioritised findings, areas with no issue found, measurement gaps and proposed validation. Hold an affected recommendation when site or analytics ownership is unclear, current index evidence is missing, the tactic is deceptive or the change needs unapproved content, routing, publication or provider actions.
