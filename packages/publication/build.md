# Check a local publication build

Use this when verifying one candidate through the publication’s configured local renderer. Confirm the requested publication, source and asset revisions, renderer, destination and expected output.

1. Run the configured local render and keep the result with the output it describes. When this route cannot run, report the blocked check.
2. Read the output and repeat the previously failing case. Use [local build checks](build/check-a-build.md) for the relevant stage, placement, disclosure or artifact question.
3. Report the compile and read-back findings. Browser behavior needs a browser check. The publisher decides release, including rights, destination and approval.

## Before handing off

- [ ] Confirm the result belongs to the requested inputs and output.
- [ ] Check the emitted route or artifact and the original failure.
- [ ] Report what is ready for review and which checks or decisions remain.
