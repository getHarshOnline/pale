# Review your own result before handing it back

A final pass by the producing agent can find omissions and unsupported claims. Use it when the artifact and criteria for acceptance are available. Independent verification still needs evidence beyond that agent's own judgment.

Reread the objective, exclusions, permissions, evidence, required output and effect limits. For each completion claim, identify the artifact or observation that establishes it. Check whether the result is correct within scope, complete against the requirements, clear enough for its recipient to use, explicit about uncertainty and unavailable evidence, and proportionate to the task.

Turn defects into concrete revisions. If a score helps compare results, define its scale and rubric while keeping blocking criteria decisive. Distinguish corrections made from corrections proposed, then recheck the affected parts.

In the handoff, state the criteria checked, supporting evidence, revisions made, unresolved gaps, basis for confidence and any independent validation still required. Leave the result unresolved when acceptance criteria are missing, the relevant artifact cannot be inspected, evidence consists only of the agent's assertion, or the consequences require another reviewer. A clean pass means this review found no defect; it does not establish that every part is correct.
