# Set visual weight from meaning

## Let importance and task choose the form

Understand the page's question before choosing a grid or filling a template. What should someone recognize first, compare, read continuously or act on? Distinguish a supporting citation, an evidence-bearing figure, a browsable record, an offer and an argument. They need not have identical anatomy or equal visual weight. Reuse a suitable component; do not force every object into cards, ruled rows or a two-column hero merely because it is available.

Assign weight through scale, position, contrast, surrounding space, material, type role and shown detail. Importance comes from the content and task, not its length or arrival order. Preserve equivalent treatment for equally important items as a set wraps. A featured item needs a meaningful distinction; an accidental orphan should not imply one. A source qualification belongs with the claim or value it limits, at a readable weight. Decorative hierarchy must not detach units, population, date or method from a figure.

Keep an object's identity and necessary qualifications across its uses. An inline reference, index row, search result and rich artifact can compose those facts differently. Neither a large panel inside prose nor an enlarged index row automatically serves the new context. Give each representation the information required for its task and a real path to the source object.

## Give different kinds of content different shapes

Evidence needs the figure, qualifying population or condition and source together. An offer needs a decision and a clear action. A record needs parallel anatomy so the reader can scan many. A citation gives identity and destination with very little weight. A narrative carries weight through type and the reading column. If all five look like bordered cards or ruled rows, the page has hidden their different jobs.

Distinguish weight within one kind only for a real distinction. A featured entry can be larger when it serves a more important reader need. The first row may simply be first by date. Keep a comparison and its qualification in one visual unit, especially when a two-column comparison stacks. A large number must not leave its necessary qualifier visually negligible; use the selected figure recipe to keep both readable together. Use lighter, parallel forms in a collection and the richer artifact at its own destination; the same anatomy can support a search result, inline citation, preview and full plate with different weight.

| Use of an object | Composition and relative weight |
| --- | --- |
| Index or collection row | Light, parallel anatomy for many units in view. |
| Inline reference | Enough identity and destination to follow without interrupting the prose. |
| Card in a related set | A compact unit whose size follows significance. |
| Rich artifact on its own page | Enough space and detail to become the page's subject. |
| Search or command result | Consistent, scannable kind and destination information. |
| Citation or preview | A small identity/source/destination view connected to its trigger. |
| Embed in another page | A bounded excerpt whose weight stays below the claim it serves. |

These are uses of the same object, not permission to change its facts or invent a second identity. Keep compared records in a useful row form; give an argument, offer or project the composition its task needs. A ruled ledger is not a universal answer.

Write the content's order of importance before looking at a screenshot. Blur the screenshot and compare its order of weight. Cover the words to see whether records, evidence and offers have distinguishable shapes. Then check that a reference never outweighs the claim it supports.

## Worked example

A report index holds source records, a featured comparison and a description. Give the featured comparison space to show its values and qualifiers. Keep source rows parallel even when one wraps. If the final row stands alone on a narrow grid, give it the same treatment rather than making it look featured. Use a caption and units that stay with the figure.
