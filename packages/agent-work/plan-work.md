# Plan work with clear restart points

Read the authorised outcome and the current sources and results it depends on. Give each part a permitted change scope, prerequisites, owner, expected result, acceptance check and return condition. Keep disputed assumptions visible and say what a resumed session must check again.

Return the proposed order and handoffs in the task's plan or reply. Identify work and approvals already completed separately from what the plan proposes.

## Before handing off

- [ ] Is each part ordered after the inputs it needs?
- [ ] Does each part have a restart point and a meaningful check?
- [ ] Can the next worker see the choices still unresolved?
