# Review a model comparison with matched resources

Use the declared workload, resource accounting and evaluation history. Check which alternatives met minimum capabilities and resource limits, which comparisons support the claim and whether a mechanism-specific control supports attribution. In the review, report trade-offs, missing measurements and whether the current method should remain. The comparison supplies evidence for the owner's decision.

## Before handing off

- [ ] Were routes compared with the same capability requirements and resource budget?
- [ ] Were quality and costs checked on matching cases?
- [ ] Is it clear where the comparison cannot support a choice?
