# Make typography carry the intended meaning

Use this to choose type roles, fix a hierarchy, keep numbers and qualifiers together or deliver the intended face. Decide what each role does in the actual language and task. Check the resulting page or film with real content.

| If you are doing this | Read this |
| --- | --- |
| Choose a face or assign a type role | [Choose reading, display, system and figure roles](type/roles.md) |
| Build a scale or improve a dense page | [Set type hierarchy, measure and rhythm](type/hierarchy.md) |
| Repair long titles, number pairs, punctuation or copying | [Keep sense and precision when lines break](type/line-breaks.md) |
| Implement or debug fonts, axes, loading or a fallback | [Deliver the face and control fallback metrics](type/fonts.md) |
| Verify contrast, wrapping, legible time and text in modes | [Read the type on the delivered surface](type/check.md) |

## Before handing off

- [ ] Do the type roles serve reading, display, controls and figures as needed?
- [ ] Do meaning, qualifiers and values survive difficult widths?
- [ ] Are the actual face, glyphs and features readable in the supported modes and intended size?
