# Review a representation comparison

Identify the study's question, model pair, hooks, permitted data and claimed difference. Read its original mathematical definitions and implementation. Apply the representation guide with numerical checks and protected comparisons. Distinguish a reported plot, saved source, a reproducible calculation and an independently supported interpretation.

Find the earliest unsupported step: artifact or history, paired rows, preprocessing or use of a split, estimator, reconstruction denominator, resource match, feature matching, label or intervention. Return the supported result and scope, missing inputs, alternative explanations and smallest check that could settle each material gap. Keep custom metrics and acceptance decisions with the study's owner.

Use an authorised existing route for a limited reproduction. Keep source review and synthetic mathematical controls separate from model execution. Dataset access, acceptance of gated licences, downloads, training, deployment and publication each need their own permission.

## Before handing off

- [ ] Do the representations, inputs and comparison rules match?
- [ ] Have reproducibility and the cases that distinguish the claim been checked?
- [ ] Do internal-feature findings stay within what the comparison supports?
