# Check material that must stay out of the output

## Inspect every generated place material can appear

Identify destination, audience, candidate, permitted sources and the owner's current withholding policy. Check that source acquisition resolves only chosen inputs. Inspect visible pages, metadata, navigation, search, feeds, machine-readable summaries, alternate formats, downloads and embedded resources where generated. A visible-page check covers only that presentation.

Run the disclosure check on the actual output inventory. In the result, state covered paths, formats, decoders, embedded items and policy rules. Identify refused formats, limits reached and missing expected output. Check paths and parsed content, including transformations or encodings the tool supports. Keep restricted values, excerpts and unredacted findings with the authorised owner. Shared results use safe rule identifiers and redacted or opaque locations; filenames and URLs can themselves disclose restricted text.

Test an allowed output and a blocked value found only in generated content or a nested resource. Test an undecodable or missing expected member and confirm that it leaves the check incomplete. Read back corrected output and associate further review with its new digest. Literal scans cover only the patterns and representations exercised. Separately assess inferred or paraphrased disclosure when the policy includes it. The publisher decides acceptance of the output.

## Exercise release checks beyond the preview

Find the publishing engine's preparation and output policy separately from its preview command. A browser-readable build can contain markup, contexts, comments or assets the release path refuses. Run the actual policy on the intended output and read diagnostics. Where appropriate, place a harmless fixture value in a private field and confirm the scan detects a simulated leak. Keep logs, captures and private source inventories with their owner.

Scan the full inventory, including scripts, structured data, assets and machine-facing routes, for unpermitted internal paths, addresses, draft notes, fixture claims and identifiers. Preserve legitimate explanation, necessary sources and qualifications. When withholding a relationship or attachment, inspect neighbouring routes for both accidental exposure and unnecessary removal of useful context.

## Worked example

Visible pages contain no private terms, but a generated search record does. Scan search, feeds and downloads along with pages. Test a safe case and a withheld marker in a nested file. State which formats were decoded and identify an undecodable expected member as unfinished. Keep raw rules and findings with the publisher, then rerun against corrected output.
