# Hand a task to the next worker

Establish the goal, recipient, current state and permission carried with the work. Use the context-handoff method to prepare the requested brief or message with blockers, next action, checks and what would make it stale. Resolve an uncertain source state or disclosure limit before handing over the affected part. Saving, sending, acceptance, activation and work-status changes each follow their own existing permission.

## Before handing off

- [ ] Does the handoff carry the goal, constraints and current result?
- [ ] Can the recipient reach the needed sources and identify the next useful action?
- [ ] Are unresolved questions that can change the outcome named with their owners?
