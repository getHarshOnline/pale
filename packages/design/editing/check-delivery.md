## Check the working frame inside the actual player

Choose dimensions, frame rate and orientation for the destination. A shared vertical edit can start at 1080 × 1920 and 30 fps, while a source-rate landscape film may belong in a 16:9 delivery. Use export-frame coordinates to plan a safe working area for captions, identifiers, visible hands and the object that changes.
