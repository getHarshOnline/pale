# Compare the cost of a model-assisted task

Identify the value of the decision, minimum acceptable quality, current owner-supplied prices or usage measurements, request route and maximum calls, time and spending. Count shared context, evaluation calls, retries and fallbacks within the same task budget. In the assessment, state which routes fit and which observations could change that finding. Recommend manual handling or report unavailable when required quality or a conservative budget cannot be established. Calling or configuring a provider is a separate action.

## Before handing off

- [ ] Were the same tasks and conditions compared across routes?
- [ ] Does the comparison include context, retries, latency and failure costs?
- [ ] Is it clear which route fits and where its limits remain?
